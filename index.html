📚 Synchronisation & Export Zotero (Entrées + Résumés FR + PDFs)
Deux méthodes intégrées pour alimenter votre Zotero :
  • Synchronisation automatique via l'API Web Zotero v3 : saisissez votre clé API Zotero (créée sur zotero.org/settings/keys/new avec droits d'écriture). Votre userID est détecté automatiquement et une collection « BiblioOstéo — RI & Ostéo-Articulaire (Cochin) » est créée avec chaque article, sa fiche résumé FR en note enfant, l'abstract original et le lien/fichier PDF.
  • Import direct en 1 clic : téléchargez le fichier biblioosteo_zotero.ris ou biblioosteo_csl.json (Fichier → Importer dans Zotero).
